# Referencias y decisiones anteriores

Estos archivos conservan el material anterior para comparación. Las entradas activas son [docs/meta](../README.md), [prompts](../prompts/README.md) y [AGENTS](../../../AGENTS.md).

- ESQUEMA-INICIAL.md y README-META-INICIAL.md: organización inicial previa a adoptar CargoMesh.
- README-CARGOMESH-BASE.md y AGENTS-CARGOMESH-BASE.md: base heredada Amazon; sus órdenes de planificación/infraestructura no se trasladan automáticamente a Meta.
- 00-CONTEXTO-RECIBIDO.md, LEEME-RECIBIDO.md y prompts-recibidos/: material entregado por el equipo, con nombres/rama que luego se adaptaron.
- CONTEXTO-CONSOLIDADO-ANTERIOR.md e INICIO-ANTERIOR.md: revisión previa de la copia inicial. Sus rutas relativas pueden referirse a la ubicación que tenían; no usar esos enlaces como comandos o rutas de trabajo.

El cambio de ubicación no altera migraciones ni despliegues. La historia Git conserva las versiones anteriores.
