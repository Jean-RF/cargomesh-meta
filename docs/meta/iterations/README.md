Todos avanzan en paralelo contra los [contratos](../contracts/README.md). Cada historia del [backlog](../backlog/README.md) conserva objetivo, lógica, backend, frontend, pruebas y vínculos. La reunión propuesta es 23:00 y el bloque de trabajo 00:00-02:00 del día siguiente; verificar disponibilidad y límites propios, sin asumir una recarga garantizada.

Daily corta: evidencia nueva, siguiente paso y bloqueo. Una tarea activa principal por dueño; review al completar el resultado. Los defectos funcionales vuelven al dueño, no se transfieren por defecto al integrador. No marcar Done una historia solo porque se crearon sus directorios.

47 historias no son un compromiso de ejecución simultánea: 27 MUST, 20 ampliaciones. El acomodo 2D/3D avanzado sigue separado del dashboard mínimo. Ajustar por capacidad real antes de prometer todo el roadmap.
