## Original artwork added in revision 5

`fabric-normal.png`, `cardboard-normal.png`, `skin-normal.png`, `paint-normal.png`, `paint-rough.png` and `grille-color.png` are original deterministic project artwork, generated by `scripts/prepare-truck-materials.mjs`. ## Human anatomy

`src/features/truck-collection/driver-base.json` derives from **Human Base Meshes 1.4.1**, the realistic male body by **Dan Ulrich**, published by Blender Studio and community contributors under **CC0-1.0**. The offline extraction script is `scripts/prepare-driver-mesh.py`; the derived file records the source blend's SHA-256. Clothing, seated pose and per-driver facial variations are project modifications. `driver-base-female.json` derives from the corresponding realistic female model in the same CC0 bundle. The extraction script accepts `--female` after the blend path and aligns the mesh with the seated pose.

- Official listing and CC0 grant: https://www.blender.org/download/demo-files/#assets
- Source archive: https://download.blender.org/demo/asset-bundles/human-base-meshes/human-base-meshes-bundle-v1.4.1.zip
- License: https://creativecommons.org/publicdomain/zero/1.0/

The Blender executable and the 49MB source bundle are not distributed in the web application. No MakeHuman/MPFB addon or its code is included.

Driver-detail revision, 31 October 2026: project modifications add eye/lid geometry, anatomical vertex shading, clipped scalp/beard surfaces, tied hair variations, shirt collar/cuffs/pocket, a fitted shoulder belt and curled fingers. The same CC0 body source is retained; no new face photographs or third-party character assets are used.

Final driver corrections integrate beard shading into the skin instead of an offset mesh, clip shirt openings continuously, and blend the scalp edge. `hair-normal.png` is an original MIT-licensed deterministic 256px tileable fibre normal map generated by `scripts/prepare-driver-hair.mjs` (also invoked by `prepare-truck-materials.mjs`); its final hash is recorded in `generated-assets.json`.
